# Google Colab + GitHub Tutorial

This repository contains a Google Colab notebook and dataset used to demonstrate
GitHub integration, reproducibility, and best practices.

## How to Run the Notebook

1. Open the notebook file in Google Colab.
2. Restart the runtime using **Runtime → Restart runtime**.
3. Run all cells from top to bottom using **Runtime → Run all**.
4. The dataset is loaded automatically from the `data/` folder.
5. The notebook will run without requiring manual file uploads.
